# Волшебное слоговое лото

Браузерная игра для педагога и ребёнка. Откройте `index.html` в браузере или разместите папку на статическом хостинге. Сборка и внешние библиотеки не нужны.

У каждого игрока карточка из 12 слогов. Выберите тип слогов, минимум четыре согласные и четыре гласные. Для двух разных карточек требуется минимум 15 допустимых сочетаний. В смешанном режиме на каждой карточке есть открытые и обратные слоги.

Автоматический режим предлагает прикрытые слоги или слоги со стечением согласных. Буквы выбирает игра. Для каждого режима можно включить гласные второго ряда (Я, Ё, Ю, Е, И).

Достаньте слог и прочитайте его вслух. Нажмите на нужный слог, чтобы камушек перелетел на ячейку. Камушек также можно перетащить. После первого верного нажатия мешочек автоматически показывает новый слог. Если этот слог есть и у соперника, он выпадет снова позже. Для победы нужно первым закрыть 12 ячеек. Педагог запускает первый ход кнопкой «Достать слог».

Для вставки в Genially используйте HTTPS-адрес опубликованной игры. Для полноэкранного режима браузеру требуется разрешение `allowfullscreen` на iframe.
